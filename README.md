## ✨ TÍNH NĂNG NỔI BẬT

<div align="center">

| 🎯 Tính năng | 📝 Mô tả |
|-------------|----------|
| 🤖 **Tự động đăng ký** | Đăng ký tài khoản Facebook hoàn toàn tự động |
| 🚀 **Đa luồng** | Hỗ trợ chạy 1-3 luồng cùng lúc |
| 🔐 **Xác thực người dùng** | Hệ thống whitelist với Hardware ID |
| 🎨 **Giao diện đẹp** | Console màu sắc, animation chuyên nghiệp |
| 📊 **Thống kê chi tiết** | Theo dõi số lượng tài khoản đã tạo |
| 🍪 **Xuất Cookie** | Lưu cookie để đăng nhập sau |
| 🆔 **Tách UID** | Trích xuất UID từ tài khoản đã tạo |
